# Pendaftaran Kejohanan (versi Claude)

Sistem pendaftaran pasukan dalam talian untuk banyak kejohanan bola tampar, berdasarkan Borang O-2 MAVA.

Versi langsung (dengan simpanan data) berjalan di claude.ai:
https://claude.ai/artifact/Tq1HhXpz73uWqWNNbnXAey

Fail `index.html` dalam folder ini ialah salinan kod sumber. Jika dibuka di luar claude.ai (contohnya GitHub Pages), ia berjalan dalam **mod pratonton**: borang boleh dicuba dan PDF boleh dilihat, tetapi data tidak disimpan. Tambah `#demoadmin` pada pautan untuk mencuba paparan admin.

## Ciri utama
- Admin cipta banyak kejohanan: nama, tarikh, tempat, tarikh dan masa tutup (MYT), tahun kelayakan.
- Kejohanan disimpan sebagai draf, kemudian diterbitkan dan dikongsi melalui pautan terus serta mesej sedia untuk WhatsApp.
- Selepas tarikh tutup: terima pendaftaran lewat dengan denda (amaun dan arahan bayaran ditetapkan admin) atau tutup pendaftaran.
- Borang O-2: 20 pemain, posisi, kapten (C), libero (L), 6 pegawai, warna 2 uniform, semakan automatik No. KP dan tarikh lahir.
- Gambar saiz pasport (35 x 45 mm) untuk pemain dan pegawai.
- Papan pemuka admin: status penghantaran, pasukan lewat, denda dibayar atau belum.
- PDF: Borang O-2, lampiran gambar, senarai induk, dan semua borang dalam satu fail.
